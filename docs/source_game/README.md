# Source Game Marketplace — Tài liệu dự án

**Cập nhật:** 2026-03-27

## Tổng quan

Nền tảng chia sẻ và bán source code game trên LAMGAME.VN, xây dựng trên Bagisto (Laravel eCommerce). Cho phép developer upload, bán source game và người mua browse, mua, download.

## Trạng thái

| Phase | Mô tả | Trạng thái |
|-------|-------|-----------|
| Phase 1 — Foundation | Listing, detail, checkout, download | ✅ Done |
| Phase 2 — Seller System | Registration, upload, dashboard, revenue sharing | 🟡 90% (thiếu earning hook + admin withdrawal UI) |
| Phase 3 — Advanced | Reviews, seller profile, version control, license | 📋 Chưa bắt đầu |
| Phase 4 — Optimization | Performance, SEO, marketing | 📋 Chưa bắt đầu |
